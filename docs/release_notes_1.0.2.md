# Sakk 1.0.2 (10) release notes

Paste into Play Console → Release → Release notes.
Also covers the 1.0.1 changes, in case 1.0.1 (9) never reached testers.

<en-US>
What's new in 1.0.2:
• Model number: save your product's model number, the one service centres ask for. Scans fill it in from the receipt.
• Tablet support: a side menu and centred screens on tablets.
• AI scans, voice add and chat keep working when the AI service is busy.
• Better offline use: no more crashes without internet, and you stay signed in.
• Bug fixes and stability improvements.
</en-US>
